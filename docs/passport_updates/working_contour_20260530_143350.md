### Важные правила

- Не публиковать кандидата без полного тела новости, если есть только обрезанный title.
- Не ослаблять общий gate ради единичной новости.
- 🔵 analytics fallback делать отдельным контуром.
- EXA/RAG добавлять как evidence layer, не как автопубликатор.
- Runtime audio/mp3/script файлы не считать частью кода.
- Перед правками: backup → py_compile → targeted pytest → dry-run → commit.
